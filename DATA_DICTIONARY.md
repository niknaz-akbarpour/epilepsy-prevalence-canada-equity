# Data dictionary

| Variable | Description |
| --- | --- |
| `geography` | Canada, province or territory |
| `sex` | Both sexes, females or males |
| `age_group_type` | Total, life-course or five-year category |
| `age_group` | Age range represented by the estimate |
| `fiscal_year` | April 1 through March 31 reporting period |
| `prevalence_percent` | Percentage meeting the selected epilepsy definition |
| `standard_error` | Standard error of the prevalence estimate |
| `lower_95_ci` | Lower bound of the 95% confidence interval |
| `upper_95_ci` | Upper bound of the 95% confidence interval |
| `prevalence_cv_percent` | Coefficient of variation expressed as a percentage |
| `case_counts` | Randomly rounded crude number of cases |
| `population` | Eligible surveillance population |
